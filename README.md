# 猜数字小游戏

> **不想装 Python？** [下载 Windows 单文件版](https://github.com/shamaya90/python-week1/releases/latest)（`gui.exe`，双击即玩）
>
> 源码运行：双击 `game.py`，或在终端里 `python game.py`；窗口版是 `gui.py`（需要 tkinter）。

## 它是什么

一个在终端里玩的猜数字游戏，记录你每局猜了几次。

## 怎么玩

1. 程序随机生成 1–100 之间的一个数；
2. 你输入猜测，它会告诉你「大了」还是「小了」；
3. 猜中后显示你猜了几次，并把这一局记录到 `scores2.csv`；
4. 每局结束自动统计历史平均次数。

## 我用到了什么

- `random.randint` 生成答案
- `while True` + `break` 控制循环
- `csv` 读写对局记录
- `pathlib` 定位文件
- f-string 输出

## 运行效果

```
猜一个数字 50
小了
猜一个数字 75
大了
猜一个数字 65
大了
猜一个数字 55
猜对了
你猜了 4 次
共 3 局，平均 5.3 次猜中
```

## 文件

| 文件 | 作用 |
|---|---|
| `game.py` | 主程序 |
| `scores2.csv` | 每局记录（时间 + 猜的次数） |

## 为什么写它

练函数、文件读写和循环，顺便看看自己平均要猜几次。
